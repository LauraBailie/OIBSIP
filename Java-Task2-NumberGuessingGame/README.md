# Number Guessing Game

Java Swing GUI game where the player guesses a system-generated
random number within a limited number of attempts.

## Tech Stack
Java, Swing

## Features
- Random number generated per round based on selected difficulty
- Too High / Too Low / Correct feedback
- Attempt counter with a max-attempts limit
- Play Again loop with round-by-round score tracking
- Difficulty levels: Easy (1–50, 10 attempts), Medium (1–100, 7 attempts), Hard (1–200, 5 attempts)

## How to Run
```
javac NumberGuessingGame.java && java NumberGuessingGame
```
