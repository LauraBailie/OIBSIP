its own README, source code, and (where relevant) a demo recording linked on
LinkedIn.

## Tech Stack
Java 17+, Swing for GUI projects. No external dependencies beyond the JDK
unless noted in a project's own README.

## Running a Project
Each folder is independent:
```
cd <task-folder>
javac *.java
java <MainClassName>
```
See the individual README in each folder for exact run instructions, demo
credentials, and feature notes.
